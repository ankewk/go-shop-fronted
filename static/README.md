# 静态资源目录

## 📁 目录结构

```
static/
├── icons/              # TabBar图标
│   ├── home.png        # 首页图标 (未选中)
│   ├── home-active.png # 首页图标 (选中)
│   ├── products.png    # 商品图标 (未选中)
│   ├── products-active.png # 商品图标 (选中)
│   ├── cart.png        # 购物车图标 (未选中)
│   ├── cart-active.png # 购物车图标 (选中)
│   ├── profile.png     # 个人中心图标 (未选中)
│   └── profile-active.png # 个人中心图标 (选中)
├── images/             # 页面图片
│   ├── banner1.jpg     # 轮播图1
│   ├── banner2.jpg     # 轮播图2
│   ├── banner3.jpg     # 轮播图3
│   ├── product1.jpg    # 商品图片1
│   ├── product2.jpg    # 商品图片2
│   ├── product3.jpg    # 商品图片3
│   └── product4.jpg    # 商品图片4
└── logo.png            # 应用Logo
```

## 🎨 图标规格要求

### TabBar图标
- **尺寸**: 24x24px (推荐使用SVG或高清PNG)
- **格式**: PNG/SVG
- **颜色**: 
  - 未选中状态: #7A7E83
  - 选中状态: #409EFF
- **设计**: 简洁、清晰、符合平台设计规范

### 应用图标
根据不同平台需要不同尺寸的应用图标：

#### 微信小程序
- **大小**: 120x120px
- **格式**: PNG
- **要求**: 圆角矩形，背景色不能透明

#### 支付宝小程序  
- **大小**: 120x120px
- **格式**: PNG
- **要求**: 圆角矩形

#### App应用
- **Android**: 
  - 48x48px (mdpi)
  - 72x72px (hdpi)  
  - 96x96px (xhdpi)
  - 144x144px (xxhdpi)
  - 192x192px (xxxhdpi)
- **iOS**:
  - 57x57px (iPhone)
  - 114x114px (iPhone Retina)
  - 72x72px (iPad)
  - 144x144px (iPad Retina)

#### H5网页
- **Favicon**: 32x32px ICO格式
- **Apple Touch Icon**: 180x180px PNG格式

## 🖼️ 图片资源

### 轮播图
- **尺寸**: 750x400px (2:1比例)
- **格式**: JPG/PNG
- **大小**: 建议每张不超过200KB
- **内容**: 高质量商品或活动宣传图

### 商品图片
- **尺寸**: 400x400px (1:1比例)
- **格式**: JPG/PNG  
- **大小**: 建议每张不超过100KB
- **要求**: 清晰、居中、背景简洁

## 📝 命名规范

### 文件命名
- 使用小写字母和短横线
- 避免使用中文和特殊字符
- 示例: `home-icon.png`, `product-banner.jpg`

### 图标命名
- 基础图标: `[name].png`
- 激活状态: `[name]-active.png`
- 示例: `home.png`, `home-active.png`

## 🔧 优化建议

### 图片压缩
- 使用TinyPNG、ImageOptim等工具压缩图片
- JPG质量设置为80-90%
- PNG使用8位色彩深度

### 格式选择
- **照片类**: 使用JPG格式
- **图标/图形**: 使用PNG格式
- **矢量图**: 优先使用SVG格式

### 适配方案
- 准备2x、3x倍率图片适配高清屏
- 文件命名: `image@2x.png`, `image@3x.png`

## 📱 平台适配说明

### 小程序平台
- 图片大小限制: 单张不超过2MB
- 支持格式: PNG, JPG, GIF, SVG
- 建议使用相对路径引用

### App平台
- 支持本地图片和网络图片
- 启动图和图标需要按平台规范准备
- 支持.9.png九宫格图片

### H5平台
- 支持所有Web标准图片格式
- 建议使用WebP格式提升加载速度
- 可以使用CDN加速

## 🚀 替换步骤

1. **准备图片**: 按照规格要求准备所有图片
2. **替换文件**: 将图片放入对应目录
3. **更新引用**: 检查代码中的图片路径是否正确
4. **测试验证**: 在各个平台测试显示效果
5. **优化调整**: 根据实际效果进行微调

## ⚠️ 注意事项

- 确保图片版权合规
- 定期清理未使用的图片资源
- 建议使用统一的设计风格
- 考虑深色模式适配
- 注意文件大小对应用包体积的影响
